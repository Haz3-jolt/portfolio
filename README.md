# harisrinivasan.dev

Source for [harisrinivasan.dev](https://harisrinivasan.dev), my personal site.

The page tells the story from writing Unity games at twelve to maintaining
[Agentic Resource Registry](https://github.com/AgenticResourceRegistry/AgenticResourceRegistry).
Each chapter is an interactive isometric object on one long workbench, and an ASCII fog driven by a
small fluid simulation drifts behind the page.

## What's on the page

| Chapter | Object |
| --- | --- |
| 2017, games in Unity | A desktop computer. Click it to open an arcade with two three.js games and shareware DOOM. |
| 2019, robots | My CS50 track bot. Drag the pegs around or knock them over and it re-plans its route. |
| 2021, Python and ML | A depth camera tracking a waving hand. |
| 2023, DASA-Bot | A rotary card index that spins to the college a student asked about. |
| 2023 to 2026, AnkiDroid | The GSoC tablet and Chromebook work, plus a phone you can review flashcards on. |
| Change Note Type | Convert a note between Anki note types and try the resulting cards. |
| 2026, Agentic Resource Registry | A filing cabinet of real skills, MCP servers, hooks, prompts and agent files. |
| 2026, Axl | One engine with three windows into the same session. |

The page ends with my latest merged pull requests, pulled from the GitHub API at build time.

## Stack

- [Astro](https://astro.build), static output with no framework runtime
- [anime.js](https://animejs.com) v4 for animation
- [three.js](https://threejs.org) for the arcade games, loaded only when the arcade opens
- Isometric SVG figures drawn with the [Anatomy](https://github.com/wheresryan22/anatomy) kit
- Hosted on Cloudflare as static assets on Workers (free plan)

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:4321.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Build the static site into `dist/` |
| `npm run data` | Fetch my merged PRs and repos from GitHub into `src/data/github.json` |
| `npm run deploy` | Build and deploy to Cloudflare |
| `npm run og` | Rebuild the 1200x630 share image `public/og.png` (macOS only: uses QuickLook and sips) |

`npm run data` reads a token from `GITHUB_TOKEN`, or from `gh auth token` if the GitHub CLI is
logged in. It works without one, but GitHub rate limits anonymous requests heavily.

## Deployment

`.github/workflows/deploy.yml` builds and deploys on every push to `main`, once a day at 03:17 UTC
so the PR list stays current, and on demand from the Actions tab. It needs one repository secret:

- `CLOUDFLARE_API_TOKEN`: a Cloudflare API token created from the "Edit Cloudflare Workers" template

The Cloudflare config lives in `deploy/wrangler.jsonc`.

## Search and answer engines

- Meta description, canonical URL, Open Graph and Twitter cards, with a share image at `/og.png`
- JSON-LD structured data (`Person`, `WebSite`, `ProfilePage`) in the page head
- `/robots.txt` and `/sitemap.xml`
- `/llms.txt` and `/llms-full.txt` ([llmstxt.org](https://llmstxt.org)), generated from the same story data as the page
- After each deploy the workflow pings [IndexNow](https://www.indexnow.org) so Bing and others recrawl

## Project layout

```
src/
  pages/index.astro     the page
  components/           chapters, demos, ledger, arcade dialog
  data/story.ts         chapter text and links
  data/github.json      generated by npm run data
  figures/              one isometric figure per chapter (*.mjs), plus its interaction (*.live.ts)
  lib/                  ASCII fog, paper texture, arcade games, page runtime, isometric kit
public/                 images and the DOOM build
scripts/                GitHub data fetcher
deploy/                 Cloudflare config
```
